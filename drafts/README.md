# Drafts

Unfinished original games, not linked from the site yet. Each is a complete game
script in the house style (uses `Arcade` and `Sound` from `assets/arcade.js`) that
still needs its page, styles, and a browser test before it moves into `assets/`.

- `chess.js`: chess against a CPU (negamax + alpha-beta, three difficulties, undo)
- `solitaire.js`: Klondike, draw one, click or drag, undo, auto-finish
- `sudoku.js`: generator with unique solutions, notes, hints, timer
- `sokoban.js`: 12 original levels, undo, swipe controls
- `hangman.js`: categories, on-screen keyboard, streaks
