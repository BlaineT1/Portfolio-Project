# Kenney sound packs

These clips come from [Kenney](https://kenney.nl)'s audio packs, released under Creative
Commons Zero (CC0): Voiceover Pack, Voiceover Pack: Fighter, Music Jingles, Sci-Fi Sounds,
Impact Sounds, Casino Audio, RPG Audio and Digital Audio. Each pack's original License.txt
sits in its folder. The manifest is `../sounds-kenney.json`.

Changes from the originals: the OGG files were converted to MP3 (so Safari on older iPhones
can play them), the preview files and footstep series were left out, and long runs of
near-identical variants were trimmed to the first few. Names are derived from the file names.
